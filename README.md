# Automated Employee Anniversary Email System

Python-based automation tool developed to automate employee
anniversary email communications.

## Overview

This automation reads employee information from an Excel file,
identifies relevant anniversaries, generates personalized email
content, and sends emails automatically.

## Key Features

- Reads employee data from Excel
- Identifies upcoming anniversaries
- Generates personalized email content
- Automates email distribution
- Reduces repetitive manual communication
- Provides processing and execution summaries

## Technologies

- Python
- Pandas
- OpenPyXL
- SMTP / Email Automation
- Excel

## Workflow

Employee Excel Data
        ↓
Data Processing
        ↓
Anniversary Identification
        ↓
Personalized Email Generation
        ↓
Automated Email Sending
        ↓
Processing Summary

## Project Structure

- `Anniversary_Auto.py` – Main automation script
- `requirements.txt` – Python dependencies
- `.gitignore` – Files excluded from version control
